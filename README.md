# Sayeed Hasan Murad — Professional Portfolio

A responsive, minimal, professional portfolio website built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — main website
- `style.css` — responsive styling
- `script.js` — mobile navigation and current year
- `assets/profile.jpg` — profile photo
- `assets/Sayeed_Hasan_Murad_CV.docx` — CV download

## Publish with GitHub Pages
1. Create a new GitHub repository (for example: `sayeed-hasan-murad-portfolio`).
2. Upload all files and folders from this project, keeping the `assets` folder intact.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)`, then save.
6. GitHub will provide your public portfolio URL.

## Custom domain
A custom domain can be connected later from **Settings → Pages → Custom domain**.
